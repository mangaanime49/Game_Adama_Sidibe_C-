# Game_Adama_Sidibe_C#

Application console C# : jeu de devinette du nombre caché, avec modes facile et difficile.

## Compilation
Se placer dans le dossier contenant Game_Adama_Sidibe_C-

```powershell
dotnet build "Game_Adama_Sidibe_C#.slnx"
```

## Exécution

```powershell
dotnet run --project "Game_Adama_Sidibe_CSharp\Game_Adama_Sidibe_CSharp.csproj"
```

## Ou bien aller dans Game_Adama_Sidibe_CSharp puis faire
```powershell
dotnet run 
```
